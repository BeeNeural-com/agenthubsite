Agentic AI

Built for agentic AI

Four resource types work together — agents discover metadata first, then fetch full bodies only when needed.

Skills

Step-by-step workflows in SKILL.md. An agent calls list_skills, finds a match, then get_skill loads the full procedure.

Agents

Specialist role definitions — research, architecture, testing, security review. Pair an agent persona with the skills it should follow.

Rules

Coding and planning standards applied automatically. list_rules surfaces conventions before implementation begins.

Prompts

Structured kickoffs for research, design, and validation tasks. Reusable templates agents fetch on demand.

MCP discovery & fetch

After connecting, your agent gets 13 stdio MCP tools. Metadata tools stay lightweight; body-fetch tools write to a local cache for faster repeat access.

list_skills get_skill list_agents get_agent list_rules get_rule list_prompts get_prompt list_bundles

CLI equivalents: agenthub search, agenthub list skills, agenthub get <id> --type skill.

RAG export

Point AGENTHUB_CATALOG_PATH at an installed catalog, then export embeddings-ready documents — one JSON object per line with id, text, and metadata.

# Export skills and agents for a vector store
export AGENTHUB_CATALOG_PATH=~/.agenthub

agenthub export-rag --output catalog.jsonl --type skill --type agent
agenthub export-rag --output web-skills.jsonl --type skill --bundles web-development

# Embed in Python without MCP
from agenthub.catalog import Catalog
cat = Catalog(catalog_path=".agenthub")
docs = cat.as_rag_documents(resource_types=("skill",))

Fetch cache

MCP get_* tools and SDK reads cache resource bodies under <catalog>/.agenthub-cache/. Safe to clear anytime — entries rebuild on the next fetch.

agenthub cache status --catalog ~/.agenthub
agenthub cache clear --catalog ~/.agenthub

Install SDK & MCP server

Packages and catalog live on the private repo BeeNeural-com/agenthub. This public site only documents the flow — install from git (token/SSH), not a full clone.

Python private git

# Set a token with repo read access (private BeeNeural-com/agenthub)
# PowerShell: $env:GITHUB_TOKEN = "ghp_..."

pip install "agenthub @ git+https://x-access-token:$env:GITHUB_TOKEN@github.com/BeeNeural-com/agenthub.git@main#subdirectory=packages/python/agenthub"
pip install "agenthub-mcp @ git+https://x-access-token:$env:GITHUB_TOKEN@github.com/BeeNeural-com/agenthub.git@main#subdirectory=packages/python/agenthub-mcp"

# Or SSH (no token in URL):
# pip install "agenthub @ git+ssh://git@github.com/BeeNeural-com/agenthub.git@main#subdirectory=packages/python/agenthub"

npm private git

# TypeScript MCP from the same private monorepo
npm install "git+https://x-access-token:${GITHUB_TOKEN}@github.com/BeeNeural-com/agenthub.git#main:packages/npm/mcp"

# Or after local build from a maintainer checkout:
# npx agenthub-mcp --stdio
# Download catalog only (no full clone) into ~/.agenthub
# Uses GitHub zipball of global/ + bundles/; needs GITHUB_TOKEN if private

agenthub install --full --target ~/.agenthub --source https://github.com/BeeNeural-com/agenthub
# Or one bundle: agenthub install --bundle web-development --target ~/.agenthub --source https://github.com/BeeNeural-com/agenthub

agenthub connect --catalog ~/.agenthub --output .cursor/mcp.json
Connect without cloning

Public docs site · private MCP repo

This landing page is meant for a public GitHub Pages host. The MCP server, SDK packages, and skill catalog stay on the private repo BeeNeural-com/agenthub. End users install thin packages + download catalog only — never clone the full private codebase.

  1. Create a GitHub token with read access to BeeNeural-com/agenthub (classic: repo scope, or fine-grained: Contents read): 
    # PowerShell
$env:GITHUB_TOKEN = "ghp_xxxxxxxx"   # or AGENTHUB_GITHUB_TOKEN
  2. pip install packages from private git (subdirectory wheels — not the whole tree): 
    python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install "agenthub @ git+https://x-access-token:$env:GITHUB_TOKEN@github.com/BeeNeural-com/agenthub.git@main#subdirectory=packages/python/agenthub"
pip install "agenthub-mcp @ git+https://x-access-token:$env:GITHUB_TOKEN@github.com/BeeNeural-com/agenthub.git@main#subdirectory=packages/python/agenthub-mcp"
  3. Download catalog only into ~/.agenthub (global + all bundles): 
    agenthub install --full --target $HOME\.agenthub --source https://github.com/BeeNeural-com/agenthub

    Uses the GitHub API zipball and extracts global/ + bundles/ only. Token is read from GITHUB_TOKEN or AGENTHUB_GITHUB_TOKEN.

  4. Generate MCP config — agenthub-mcp on PATH + local thin catalog: 
    agenthub connect --catalog $HOME\.agenthub --output .cursor\mcp.json

              Variable
              Purpose
            

          
          
            

              AGENTHUB_CATALOG_PATH
              Installed catalog directory (e.g. .agenthub/ or repo root for dev)
            

            

              AGENTHUB_BUNDLE
              Comma-separated bundle filter — full company preset (all 21 bundles) in Dev tab, or subset e.g. web-development,software-engineering-general,product-management,security

              Fetch cache override (default: <catalog>/.agenthub-cache/)
            

            

              AGENTHUB_TOOL_DESC_MODE
              active (default) or passive MCP tool descriptions

CLI commands

            
All commands run against AGENTHUB_CATALOG_PATH (source for install, installed dir for list/search/get).

            

              
# Search
agenthub search react
agenthub search "threat model" --bundles security

# List
agenthub list skills
agenthub list skills --bundles web-development
agenthub list bundles

# Fetch one resource body
agenthub get nextjs-development --type skill
agenthub get threat-modeling --type skill

# Install one bundle or single skill
agenthub install --bundle web-development --target ~/.agenthub --source https://github.com/BeeNeural-com/agenthub
agenthub install --skill threat-modeling --target ./kb --source https://github.com/BeeNeural-com/agenthub
